# Demo personas

Every person here is made up. Phone numbers use the fictional 555-01xx range, emails use the reserved `example.com`/`.net`/`.org` domains, SSNs come from the 987-65-432x block set aside for advertising, and card numbers are Stripe test cards.

To demo someone, click **Reset demo** on `/formly`, then upload that person's folder with **Upload**. Each folder has the same three files: `personal_info.txt` (their own notes, each written in a different style), `contacts.csv` and `google_profile.json`. Or connect **Google** and pick the person from the account switcher on the sign-in screen (Alex Chen, Jamal Washington and Aisha Bello have a resume in Drive).

For the **SpaceXAI application** (`/spacexai`), use one of the three people with a `resume.docx`. Alex has the deepest resume (telemetry work and a student rocketry team), Jamal applies as a CS junior with class and side projects, and Aisha brings Army satellite networking. Everyone else has no resume, so the short answers stay blank instead of being made up.
